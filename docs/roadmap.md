# MedViz Roadmap

## v1 (Current)
- STL import and interactive 3D viewer
- Orbit navigation (rotate/pan/zoom)
- Scene presets and themed UI
- Slicing/clipping plane with persistent cut
- Basic transform tools
- Model metadata panel (name, size, triangles, vertices, bounds)

## v1.1
- Measurement tool with mm labels
- Marker/annotation system + marker list + JSON export
- STL export after applied edits
- PNG screenshot export

## v1.2
- OBJ/PLY import support
- OBJ export and HTML report export
- Wireframe/normal debug shading modes
- Large model guardrails + warnings
- Optional simplification fallback

## v2+
- Advanced trim and undo stack
- Multi-model compare mode
- Collaboration and cloud sessions
- WebGPU rendering path
