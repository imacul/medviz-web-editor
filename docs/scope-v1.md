# MedViz Scope v1 (Working Baseline)

This repository is aligned to the MedViz v1 direction:

- Web-based 3D medical mesh viewer
- Clinical-first UI (top bar, tool panels, model info, status bar)
- STL import pipeline
- Orbit navigation, slicing, transform, and light editing primitives
- Export/report features planned in next iterations

The complete authored scope text is being used as the implementation reference for subsequent milestones.
